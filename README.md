## HardwareHub_FlutterAccess

### Dependencies      

**=> permission_handler: ^11.4.0**

Permission_handler is used to ask user permission  (like camera, location, storage, microphone, etc.) , to handle user response and to open app setting for manual enabling.

**=> torch_light: ^1.1.0**

Flutter plugin that allow to control the device flashlight (torch) on and off .

**=> google_maps_flutter: ^2.5.0**

To embed Google Maps into your Flutter app.

**=> geolocator: ^11.1.0**

Fetch current device location and to track user movement in real-time . Also it checks and handle the permission request for location . 

**=> local_auth: ^2.1.7**

Provides access to local biometric authentication like fingerprint scanning , Face recognition , Passcode or PIN .

## App Features

### Flash On/Off

**A simple torch icon that toggles on when tapped, and turns off when tapped again.**

### Biometric Authenticaton

**A simple fingerprint icon that, when tapped, displays a dialog prompting the user to scan their fingerprint.
Below the dialog, a message is shown indicating whether the authentication was successful or failed.**

### Tracking Location

**A live location tracking feature that fetches the user’s current GPS location and displays it on a Google Map.
The map updates in real-time as the user moves, and a marker indicates the user’s current position.**
